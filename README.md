# Pinkfolio — Personal Portfolio

Website portofolio pribadi milik Nia Anastasya Ramadhani, mahasiswa Teknik Informatika Universitas PGRI Ronggolawe Tuban. Website ini dibuat dengan desain modern, responsif, dan menggunakan tema Pastel Pink.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript

## Fitur Website

- Homepage dengan navigasi utama.
- Biodata dan informasi pribadi.
- Daftar keterampilan (Skills).
- Portfolio yang menampilkan empat proyek.
- Halaman detail untuk setiap proyek.
- Contact section dengan validasi formulir.
- Desain responsif untuk laptop dan perangkat mobile.
- Animasi dan efek hover.
- Navigasi hamburger pada tampilan mobile.

## Daftar Proyek

1. **Project 01 — Website Portofolio Pribadi**  
   Pembuatan website portofolio menggunakan Visual Studio Code, HTML, dan CSS.

2. **Project 02 — Sistem Informasi Kegiatan Mahasiswa**  
   Pembuatan sistem informasi menggunakan PHP dan MySQL.

3. **Project 03 — Bendahara Umum HIMA-TIF**  
   Pengalaman organisasi dalam mengelola dan mengawasi pemasukan serta pengeluaran keuangan, termasuk koordinasi dengan bendahara pelaksana kegiatan IMBIE.

4. **Project 04 — Desain Poster Digital**  
   Pembuatan desain poster digital menggunakan Canva.

## Cara Menjalankan Website

1. Unduh atau clone repository proyek.
2. Buka folder `pinkfolio-portfolio` menggunakan Visual Studio Code.
3. Pastikan seluruh file dan folder pendukung tersedia.
4. Jalankan file `index.html` menggunakan browser atau ekstensi Live Server.
5. Website dapat dilihat melalui browser.

## Formulir Kontak

Formulir kontak dilengkapi validasi dasar menggunakan JavaScript untuk memeriksa kelengkapan data dan format email. Saat ini formulir belum terhubung dengan server sehingga belum mengirim pesan secara langsung.

## Catatan

- Website menggunakan Google Fonts yang memerlukan koneksi internet.
- Website dirancang agar dapat menyesuaikan tampilan pada laptop maupun perangkat mobile.
- Gambar proyek menggunakan atribut `alt` dan optimasi pemuatan gambar dengan `loading="lazy"`.
